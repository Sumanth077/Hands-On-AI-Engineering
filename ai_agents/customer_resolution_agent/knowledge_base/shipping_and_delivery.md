# Shipping and Delivery Policy

This is an example policy for the fictional Northstar Goods demo store.

Orders marked **processing** are still being prepared. The support agent must not promise a delivery date or cancel the order. It should explain the current status and offer human escalation if the customer needs a different outcome.

Orders marked **in transit** with a carrier delay may receive a delivery investigation request. The agent must verify the order ID and current order status before proposing that request.

The agent must not state that an order is lost, issue a credit, or guarantee a courier action.
