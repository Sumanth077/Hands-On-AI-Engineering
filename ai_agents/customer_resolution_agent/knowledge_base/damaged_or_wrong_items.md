# Damaged or Wrong Item Policy

This is an example policy for the fictional Northstar Goods demo store.

Customers may request a replacement review when an item arrives damaged or differs from the item shown in the order record. The agent must collect the order ID and a short description of the problem.

The agent should confirm the order status and eligible resolution from the order record before proposing a replacement request. The agent must ask the customer to confirm that a replacement is the resolution they want.

A replacement is not created automatically. The agent records a request only after human approval.
