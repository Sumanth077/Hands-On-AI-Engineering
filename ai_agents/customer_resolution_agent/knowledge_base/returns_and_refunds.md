# Returns and Refunds Policy

This is an example policy for the fictional Northstar Goods demo store.

The agent can explain that a return review may be available when the order record lists `return_review` as an eligible resolution. It must not promise a refund amount, approve a refund, or claim that a refund has been issued.

If the customer disputes a payment, requests an exception, or asks for a resolution not listed in the order record, the agent must offer human escalation.
